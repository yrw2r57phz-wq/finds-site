About Finds

Finds is a personal, non-commercial music discovery and playlist management project developed and operated by a single individual.

The project helps its owner organize music identified from previously saved Instagram posts and find corresponding recordings on YouTube.

Finds uses the YouTube Data API v3 to search for music, retrieve playlist information, verify playlist ownership, and add selected videos to a personal YouTube playlist.

Google OAuth authorizes access to the owner's YouTube account. OAuth credentials are managed through GitHub Actions Secrets.

To reduce unnecessary API requests, Finds processes identified tracks in batches, checks for existing playlist entries, and caches previous search results. A separate Spotify API integration supports personal music matching and playlist workflows.

This website is informational only. Finds does not offer public accounts or access to the private tool.

Privacy Policy

Scope. Finds is a private, single-user project. This website provides information only; it does not offer registration or public sign-in.

Data processed. Finds processes saved Instagram links, reviewed artist and track information, YouTube search results and video IDs, and playlist metadata for personal music organization.

YouTube access. Finds uses the YouTube Data API v3 and Google OAuth to search for recordings, read playlist information, verify playlist ownership, and add selected videos to the owner's playlist. YouTube use is subject to the YouTube Terms of Service and Google's Privacy Policy.

Authentication. OAuth credentials are stored as GitHub Actions Secrets and supplied to private Python workflows. The reviewed code exchanges a refresh token for an access token and does not explicitly save tokens to its report or cache files.

Storage. Music records, search-result caches, and import progress are maintained in a private GitHub repository. Some run reports are uploaded as GitHub Actions artifacts. Search-result caching is used to avoid repeated API requests. Cached YouTube search results are timestamped and expire after 29 days; entries without a known retrieval date are discarded.

Third-party services. The project uses Google/YouTube, GitHub for hosting and workflow execution, and Spotify for separate music matching and playlist-related functions. The website itself is hosted by GitHub Pages, which may process visitor technical information.

Privacy questions and deletion requests. As this is a single-user project, the developer manages data deletion directly. For questions about the project or privacy practices, contact the developer through GitHub. Removing data stored by Finds does not remove content stored by YouTube; YouTube content must be managed through YouTube.

Control. The owner can stop the workflows and revoke Google account access via Google Account connections. Project records can be reviewed and removed by the owner from the private repository.

Retention. Search metadata and progress records are retained to support the project. Cached YouTube search results expire after 29 days. Import progress and manually reviewed music identifications are maintained for the ongoing personal project. The developer can remove stored project data from the private repository. Historical repository commits and workflow artifacts may require separate cleanup. This project has not been certified as compliant by YouTube.
