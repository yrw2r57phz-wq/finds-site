Finds is a personal, non-commercial project for rediscovering music from saved social media posts and organizing identified recordings into personal playlists.

About Finds

Finds is a personal, non-commercial music discovery and playlist management project developed and operated by a single individual.

The project helps its owner organize music identified from previously saved Instagram posts and find corresponding recordings on YouTube.

Finds uses the YouTube Data API v3 to search for music, retrieve playlist information, verify playlist ownership, and add selected videos to a personal YouTube playlist.

The application uses Google OAuth for authorized access to the owner's YouTube account. OAuth credentials are managed through GitHub Actions Secrets.

To reduce unnecessary API requests, Finds processes identified tracks in batches, checks for existing playlist entries, and maintains a cache of previous search results.

A separate Spotify API integration supports personal music matching and playlist synchronization.

This website is informational only. Finds is not a public music streaming service and does not offer registration or access to other users.

Privacy Policy

Scope. This website is an informational page for a personal, single-user project. It does not provide user registration or a public sign-in flow.

Data used by Finds. The private tool processes saved Instagram post links, manually reviewed music identification information, YouTube search results, YouTube video IDs, and playlist data needed to organize the developer's own playlists.

Google and YouTube. Finds uses the YouTube Data API and Google OAuth to access the developer's own YouTube account for authorized playlist actions. Use of YouTube is subject to the YouTube Terms of Service. Google's Privacy Policy describes Google's handling of information.

OAuth credentials. The application uses Google OAuth credentials stored through GitHub Actions Secrets. Access tokens are obtained through Google's OAuth token endpoint for authorized YouTube API requests. The reviewed import and synchronization code does not explicitly write OAuth tokens to project data files.

Data storage. Finds maintains music identification records, YouTube search metadata, playlist references, search caches, and import progress information in its private project environment. Some reports are also stored as GitHub Actions artifacts.

Third parties. The workflow uses Google and YouTube, GitHub for private code execution and storage, and the Spotify API for separate music matching and playlist synchronization.

Access and control. Only the developer is intended to use the tool. The developer can stop using the tool and revoke its Google account access through Google Account connections.

Website hosting. This page is hosted by GitHub Pages. GitHub may process technical visitor data under its own policies.

Data retention and deletion. The project retains music metadata, search caches, and import progress to support its personal workflows. Data retention, refresh, and deletion procedures are being reviewed against applicable YouTube API Services policies before the quota extension application is submitted.
